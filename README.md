# Kawa Sushi & Wok preview

Responsive restaurant demonstration in French, English and Arabic. The menu is editable in `src/menu.js`, with display translations in `src/menu-translations.js`.

Menu and delivery prices: [Kawa Sushi on Glovo](https://glovoapp.com/fr/ma/meknes/stores/kawasushi-mks-19e51), observed 22 October 2026. Prices at the restaurant may differ. Address and phone: [Google Maps listing](https://maps.app.goo.gl/zqYQK9UXciWg99Ma8).

The food photographs were generated for this demonstration. They do not depict actual Kawa dishes. Obtain restaurant approval and replace them with commissioned photos before official publication.

`pnpm install && pnpm dev` for local preview. `pnpm build` for static output. GitHub Pages publishes changes on push to `main`.
