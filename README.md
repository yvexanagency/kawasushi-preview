# Kawa Sushi & Wok preview

Static site in French, English and Arabic. Edit menu items and prices in `src/menu.js`.

Menu and delivery prices: [Kawa Sushi on Glovo](https://glovoapp.com/fr/ma/meknes/stores/kawasushi-mks-19e51), observed 22 October 2026. Prices at the restaurant may differ. Address, phone and photographs: [Google Maps listing](https://maps.app.goo.gl/zqYQK9UXciWg99Ma8). Photographs are used provisionally for this sales demonstration. Obtain permission before official use.

`pnpm install && pnpm dev` for local preview. `pnpm build` for static output.
